# Slopify

## [![Discord Invite](https://img.shields.io/discord/1242655121234460723?style=for-the-badge&logo=discord&logoColor=white&label=Discord&labelColor=%235865F2&color=%23FFFFFF&link=https%3A%2F%2Fdiscord.gg%2Fz3kjUmCCmv)](https://discord.gg/z3kjUmCCmv)

_"The [ideomotor effect](https://www.newmanmentalism.com/blog/a-mentalist-explains-how-ouija-boards-work-and-the-ideomotor-effect) of software"_

**The worst hackathon in the world.** No teams, no judges, no theme, no demo day
— just a season-long free-for-all where the goal is to ship slop.

Everything ships into **one shared directory**: the current season folder,
[`slopify.dev/season-1/`](slopify.dev/season-1/). Not your own subfolder — that
one directory, directly, alongside everybody else's stuff. The collisions are
what make the planchette move.

Contributions are accepted on [GitCamp](https://gitcamp.net/SimuCorps/Slopify)
only. See [CONTRIBUTING.md](CONTRIBUTING.md).

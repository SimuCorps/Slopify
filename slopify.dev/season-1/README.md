# Season 1

This is where Season 1 contributions live.

## Where to put your thing

One directory per contribution, named after it:

```
slopify.dev/season-1/your-thing/
```

Whatever goes inside is up to you. Any language, any framework, any build system,
any level of seriousness. One file or forty. There is no required structure, no
required README, and no required anything.

If your contribution has a web-visible piece, an `index.html` in your directory
means it can be linked from the season index.

## How to submit

Contributions are accepted **on GitCamp only** — not GitHub.

1. Sign up at [gitcamp.net](https://gitcamp.net)
2. Fork [SimuCorps/Slopify](https://gitcamp.net/SimuCorps/Slopify)
3. Add your directory here
4. Open a pull request from your fork into `main`

## The only real rules

Nothing illegal. No malware, miners, or exfiltration. No harassment or targeting
real people. No secrets or other people's private data.

Everything else is fair game, including AI-generated code. It's called Slopify.
